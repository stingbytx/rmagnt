About

About Remy Agent

A real-time AI voice and chat assistant by DotcomAI, powered by NVIDIA-hosted inference through a proxy you control. Here is how it works and what it stores.

01 Pipeline

Microphone → browser speech recognition (ASR) → your proxy → NVIDIA chat-completions model → spoken reply through the browser's speech synthesis engine (TTS).

Turn detection comes from the recognizer's own segmentation plus an amplitude gate on the mic stream. Interrupting the agent cancels playback and the in-flight request immediately.

Model
Yours to choose — any chat-completions endpoint on your NVIDIA account.
Audio
Never sent to the LLM, never written to disk.
Limitation
Native speech-to-speech is not used: speech recognition and synthesis are browser-native, so the model sees text.

02 What is stored

Settings live in localStorage. Transcripts are stored locally only when you leave "Save conversations" on, and you can delete them individually or all at once.

Your NVIDIA API key is never part of this page, its bundle, or this repository. It sits in your proxy's environment. If you use the optional app token, it is held in sessionStorage and disappears when the tab closes.

Your proxy and NVIDIA process the conversation text under their own retention policies — this app cannot make claims about those.

03 Accessibility

Every control is a real button with an accessible name and visible focus. Conversation state is announced through an aria-live status region and mirrored in the header chip. Reduced-motion preferences disable orb animation. Touch targets stay above 44px on mobile.

04 Deploying

Static files only — no build step. Push index.html, app.js and .nojekyll to a repo, enable GitHub Pages on the branch root, then paste your proxy URL in Settings.

The same repo ships worker.js (Cloudflare Worker) and a zero-dependency server.mjs for local testing.

05 Frequently asked questions

What is Remy Agent?

Remy Agent is a real-time AI voice assistant built by DotcomAI. You speak or type, and an AI model answers — spoken aloud and shown as a live transcript.

Is Remy Agent free to use?

The web app itself is free to use. Model access depends on the inference account behind this deployment, including its rate limits and quotas.

Can I choose different AI models?

Yes. Any chat-completions model available to this deployment can be selected in Settings, and the list can be fetched live.

Does Remy Agent support multiple languages?

Yes. Choose a language in Settings to drive speech recognition and spoken output. The browser supplies the voices, so available languages depend on your device, and the model replies in the language you use.

Can I use Remy Agent on mobile?

Yes. The interface adapts to phones and tablets. Typing works in every browser; voice input needs a browser with the Web Speech API, such as Chrome or Edge on Android.

Does Remy Agent store voice conversations?

Audio is never recorded or uploaded. Transcripts are kept only in your own browser storage when conversation history is enabled, and you can delete them at any time in Settings.

How do I start a conversation?

Press Start talking and allow microphone access, or type a message in the composer. Replying aloud can be turned off in Settings.
